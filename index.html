Обеспеченность образовательной инфраструктурой Ростова-на-Дону

Интерактивная карта показывает пространственную обеспеченность населения Ростова-на-Дону образовательной инфраструктурой и помогает выявлять территории с высоким уровнем дефицита доступности.

Как читать карту

Выберите один из четырёх режимов анализа: детские сады, начальная школа, средняя и старшая школа или интегральная оценка.

Ячейки сетки окрашены согласно пятибалльной шкале оценивания: чем темнее ячейка, тем ниже обеспеченность.

Пунктирные контуры показывают зоны нормативной доступности выбранного типа образовательной инфраструктуры.

При приближении подгружаются жилые здания; по ячейкам и объектам можно открыть выноски с расчётными показателями.

Методология

Расчёты выполнены на гексагональной сетке 500×500 метров. Для тематических режимов оценивается население ячейки, население в зоне нормативной доступности и доля обеспеченного населения, для интегрального режима используется сводная балльная оценка по нескольким типам образовательной инфраструктуры.

Данные и ограничения

Для создания набора данных по жилым зданиям, их местоположению и населению использовались данные: ГИС ЖКХ, How old is this house; для создания набора данных по образовательным объектам — данные Администрации города Ростова-на-Дону, открытых геоинформационных справочников; для определения административных границ — данные портала OpenStreetMap, а также картографическая подложка CartoDB Positron. Карта предназначена для предварительного аналитического просмотра и не заменяет детальное проектное обследование.
