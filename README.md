## Назначение проекта
Проект представляет собой интерактивную аналитическую веб-карту обеспеченности Ростова-на-Дону образовательной инфраструктурой. Карта ориентирована на специалистов городской администрации и может использоваться для предварительного выявления территорий с дефицитом доступности детских садов и школ.

## Режимы анализа
В веб-карте доступны четыре взаимоисключающих режима просмотра:

1. обеспеченность детскими садами;
2. обеспеченность начальными школами;
3. обеспеченность средними и старшими школами;
4. интегральная оценка пространственной обеспеченности.

## Использованные данные
Для создания набора данных по жилым зданиям, их местоположению и населению использовались данные ГИС ЖКХ и How old is this house. Для создания набора данных по образовательным объектам использовались данные Администрации города Ростова-на-Дону и открытых геоинформационных справочников. Для определения административных границ использовались данные OpenStreetMap. В качестве картографической подложки используется CartoDB Positron.

## Методология
Расчёты выполнены на гексагональной сетке 500×500 метров. Для режимов детских садов и школ в каждой ячейке рассчитаны население ячейки, население в зоне нормативной доступности и доля обеспеченного населения. Для этих режимов применяется пятибалльная шкала: менее 20 процентов, 20–40 процентов, 40–60 процентов, 60–80 процентов, более 80 процентов.

Интегральная оценка показывает сводный уровень пространственной обеспеченности образовательной инфраструктурой по нескольким показателям.

## Функциональность веб-карты
- одиночное переключение между четырьмя режимами анализа;
- интерактивная легенда, меняющаяся в зависимости от выбранного режима;
- попапы по ячейкам с населением, населением в зоне доступности, круговой диаграммой и оценкой доступности;
- попапы по зданиям школ, детских садов и жилым зданиям;
- поиск по названиям и адресам школ и детских садов, а также по адресам жилых зданий;
- масштабная линейка в метрической системе;
- кнопка полноэкранного режима;
- информационная плашка с описанием проекта и методологии.

## Оптимизация
Исходный экспорт qgis2web был оптимизирован: тяжёлые слои жилых зданий не загружаются сразу при открытии карты, а подгружаются только на крупном масштабе. Для поиска используется отдельный облегчённый индекс.

## Что было самым сложным
Самой сложной частью стала оптимизация веб-карты и настройка логики переключения слоёв: из-за большого количества жилых зданий стандартный экспорт qgis2web оказался слишком тяжёлым, поэтому структура веб-карты была переработана.
